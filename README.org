* Hi there 👋
I'm [[https://www.smallbutton.com][@andreasknoepfle]] and this is a collection of private config files and setup scripts for macOS.
Feel free to grab & steal anything you like 🎯.

** Contents
*** Editor & terminal
- ~.doom.d/~ [[https://github.com/doomemacs/doomemacs][Doom Emacs]] configuration (including [[https://github.com/xenodium/agent-shell][agent-shell]] for Claude)
- ~.wezterm.lua~ [[https://wezterm.org/][WezTerm]] terminal config
- ~.vimrc~ Minimal vim config

*** Shell
- ~.zshrc~ & ~.zshenv~ zsh config, with plugins managed by [[https://getantidote.github.io/][antidote]]
- ~.zsh_plugins.txt~ Plugin list for antidote (spaceship prompt, a few oh-my-zsh plugins, fzf-marks)
- ~bin/~ Small helper scripts (added to ~PATH~ by ~.zshrc~)

*** Tooling
- ~Brewfile~ Homebrew packages, casks, Go tools and npm packages (~brew bundle~)
- ~.default-gems~ Default gems for new Ruby installs (managed by [[https://mise.jdx.dev/][mise]])
- ~.gitignore_global~ [[https://git-scm.com/docs/gitignore][Global gitignore]]

** Installation
~bin/install-mac~ installs Homebrew, everything in the ~Brewfile~, Doom Emacs, and symlinks the dotfiles into ~$HOME~.
It is more of a reference for me than a polished installer, so read it before running it.
